# Appeal Kit (preview)

Compare a Wake County, NC home's assessed value with recent qualified sales of similar homes nearby, and download the
evidence as a PDF. Self-help only: **not legal, tax or appraisal advice**. No recommendations; Appeal Kit never
represents anyone. Until Wake publishes 2027 values (by Jan 22, 2027), results use 2024 assessed values.

Data: Wake County Tax Administration public data files; Parcel Address Points from Wake County Open Data
(CC-BY-4.0, credit: Wake County GIS).

Run: `pip install -r requirements.txt && streamlit run streamlit_app.py`
